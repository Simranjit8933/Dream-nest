# DreamNest

A stays booking website (like Airbnb) with an AI trip planner.

**Live demo:** https://dreamnest-rdx3x2e9a-simranjit8933s-projects.vercel.app/

## Features
- Browse stays with a photo slider on every card
- Search, filters and map view
- Wishlist, login and signup
- Booking with a clear price breakdown
- Reviews from real guests
- AI Travel Copilot for trip plans

## Built with
React, Vite, Node.js, Express, MongoDB

## Run locally
1. Server: `cd server`, then `npm i`, copy `.env.example` to `.env`, then `npm run seed` and `npm run dev`
2. Client: `cd client`, then `npm i` and `npm run dev`
3. Open http://localhost:5173
